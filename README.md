# detection-lab

Detection engineering lab — Sigma / Sysmon / Splunk / ELK experiments, detections and notes.

## Getting started

```bash
git clone git@github.com:Ctum0/detection-lab.git
cd detection-lab
```

## Layout

- `detections/` — detection rules (Sigma, Splunk, KQL, etc.)
- `lab/` — lab setup notes (Sysmon config, log sources)
- `notes/` — research notes and writeups
